## 🚀 Features Matrix

| Feature | Description |
| :--- | :--- |
| **Mass Reporting** | 500+ threads ke sath heavy reporting capacity. |
| **Auto ID Fetcher** | Username dete hi backend se numeric ID automatically nikal leta hai. |
